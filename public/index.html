Data integrity

    About this view. The Power BI report has its own data model, so it does not change when you edit rows in this site. Your editable, live data is on the and tabs. Use the export panel to feed the same rows into Power BI.

    Power BI report

    Open in Power BI ↗

    Your link is a share link, not an embed link

    Power BI share links (app.powerbi.com/links/…) open the full Power BI app and require a Microsoft sign-in, so browsers refuse to show them inside another website. To display the report here, paste an embed URL:

    1. Public report: in Power BI → File → Embed report → Publish to web (public) → copy the link that starts with https://app.powerbi.com/view?r=. Anyone with the link can see the data, and your admin must allow it.
    2. Private report: File → Embed report → Website or portal → copy the link starting with https://app.powerbi.com/reportEmbed?. Viewers sign in with a Microsoft account that has access.

    · The report not showing? Some embed links need you to sign in to Microsoft in this browser first.

    Live push to Power BI

    status

    Checking…

    Every add / edit / delete is sent to your Power BI streaming dataset within ~1 s, whoever made it and however they connected (localhost or Cloudflare). See POWERBI_LIVE_SETUP.md for the 5-minute setup.

    Use this data in Power BI

    1. Download the CSV below, or with the server running use the live address /api/export.csv.
    2. In Power BI Desktop: Get data → Text/CSV (file) or Web (the live address, via your Cloudflare link).
    3. After edits here, click Refresh. In the Power BI service, scheduled refresh runs a few times a day; true live tiles need a streaming or push dataset.
